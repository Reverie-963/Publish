# 文件索引与 HTML 预览

将文件夹变成可浏览的 HTML 入口，点击资料先看到预览，原件保留。默认入口名 `00 - 文件索引.html`，方便按名称排序时靠前；Finder 的文件夹优先、手动排序等设置仍可能影响位置，不保证系统级置顶。

## 工作流程

1. 确定根目录、范围与既有顺序，阅读 [结构与导航](references/layout-and-navigation.md)。课程材料保留网页顺序；普通文件夹沿用自然文件名顺序。用户指定文件名和布局优先。
2. 使用 `scripts/build_folder_index.py ROOT` 生成递归索引和预览，详见 [文件类型与生成](references/file-previews.md)。先在样例或任务范围内运行，检查转换结果，保留所有原件。
3. 严格使用下述界面约定及共享模板，保留目录展开与返回后的滚动位置；不要自行改成文件管理器。
4. 对用户实际需要的类型验证打开效果。无法完整预览时直接写明能力边界，保留“打开原件”，不把下载冒充预览、文本提取冒充原版、空白页冒充成功。
5. 交付真实入口链接与重要限制。验证记录放工作区，不要求为了记录验证而新写报告。

## 固定的界面约定

除非用户明确要求改变，生成结果必须同时满足：

- **索引页**：居中的单栏递归文件树，仅显示标题、必要导航、层级和文件链接。文件夹名称可点击进入独立子目录页，箭头保留同页展开/收起；子目录提供上一级和总索引。使用 `assets/navigation-template.html`；不做左目录右预览，不加常驻侧栏、预览框、搜索栏、卡片切换或统计面板。
- **阅读页**：点击资料直接进入独立 HTML。沿用 `assets/reader.css`：与目录页一致的背景、居中单栏宽度和留白，正文直接铺在页面上，不套白色纸张卡片、边框、圆角或阴影；标题、返回链接和分隔线沿用目录页的简洁形式。紫色链接及清晰的表格样式保留。文稿目录默认关闭，展开时推开正文，没有遮罩；这只是当前文章目录，不是文件浏览器。正文保留一个“返回总索引”。必要样式内嵌，离线或嵌套路径下不能退化成无样式正文。
- **展开控件**：标题旁只放一个无边框、无底色、无阴影的双箭头图标。只要任意层级有一个目录展开，图标含义与动作都是“全部收起”；所有目录关闭时才是“全部展开”。保留按钮语义、键盘焦点、悬停说明和无障碍名称，不显示文字按钮。使用 `assets/navigation.js`，新旧生成接口必须一致。
- **整页缩放**：索引、子目录和阅读页共用 `assets/page-zoom.css/js`，同步缩放文字、图片和表格并重新排版。标题旁仅显示低调的当前比例，点击才展开缩小、恢复 100%、放大；支持页面收到的 Cmd/Ctrl 加减、0 和带修饰键滚轮手势，普通滚动不拦截。浏览器允许存储时同一文件夹沿用比例，存储禁用仍可调整；图片不再默认点击打开独立放大界面。不要通过单独放大图片代替整页缩放，不使用 transform 缩放造成裁切。
- **代码与滚动条**：代码文件及标明语言的 Markdown 代码块在生成时着色，保留完整可复制文本，未知语言显示原文；不执行代码，不依赖在线资源；代码块背景透明，无边框、阴影或卡片外壳。滚动条使用细、浅色圆角滑块和透明底轨，保留原生滚动与拖动，不用自绘滚动层。
- **存放位置**：入口为 `00 - 文件索引.html`；新增阅读页、子目录页、转换资源和清单继续集中在 `.file-index/`。同一路径的原件保持稳定预览地址，不为布局更新移动原件或散落新 HTML。

复现的是上述阅读体验，不照搬参考课程的内容。实际视觉、DOM 逻辑和本地链接验证分别记录；只做静态或模拟测试不能声称已在浏览器看过。

## 报告独立

本技能不创建、补写或要求 `报告.md`、`任务报告.md`。存在报告时按普通 Markdown/文档处理，自动生成预览并列入文件树；不存在时索引照常工作。需要工作报告时，由任务根据工作量和用户要求另行使用 [task-work-report](../task-work-report/SKILL.md)，它只写已完成和待审核确认事项。

论文、课程报告、文章审核版都是普通源文件；不要因名称包含“报告”而重写内容。

## 工具与兼容

文件索引生成器、预览适配器及样式集中在本技能。所有新预览和状态放根目录 `.file-index/`，不散落到材料旁；HTML 离线读取已生成内容，不依赖运行时 fetch 或服务器。源文件的已有相对链接须保持可用。

原 `scripts/build_html_readers.cjs` 保留为同目录 Markdown 阅读页兼容工具，使用见 [旧阅读页接口](references/html-readers.md)。翻译技能旧脚本继续转发到它。新索引不强制重建所有旧 HTML；保留已有有效阅读版与用户页面，不覆写不属于本生成器的同名文件。

索引和报告是独立技能；文档翻译、Moodle 归档和视频文稿只在需要导航时调用本技能，不因调用导航而强制提交报告。
