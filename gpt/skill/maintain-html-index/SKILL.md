# 本地 HTML 索引维护

集中维护一套离线导航规则、模板和工具。先阅读 [组织与导航规范](references/layout-and-navigation.md)，仅处理用户指定的目录和本次变动。

## 独立使用与技能调用

- 用户仅要求索引时，直接根据现有本地成果和已核实的在线入口工作，不启动下载、翻译或转录。
- 其他技能完成内容工作后，读取本技能并执行导航维护步骤；“调用”指同一任务加载本技能，不需要另开聊天或子代理。
- 调用方提供：索引根目录、受影响文件及资料顺序、源文件与译稿/答案/视频的对应关系、已核实在线入口、路径变更映射（如有）、需保留的原文对照入口，以及已经整理好的报告内容。
- 源文件命名、翻译语言、转录质量和课程网页顺序由调用方负责。本技能不推测缺失内容、不改写报告结论，也不因更新技能而批量迁移既有课程。
- 相关技能应安装在同一技能根目录。优先用会话给出的实际技能位置；只有未提供位置时才从 `${CODEX_HOME:-$HOME/.codex}/skills/maintain-html-index` 查找。

## 执行

1. 读取已有索引与实际文件，保留资料顺序、有效入口及用户说明。核实本次变化；没有变化则不重写索引。
2. 复用 [导航模板](assets/navigation-template.html)，把完整资料树写入 HTML。各层文件夹原地展开，具体文件才跳转；已有子索引可保留，但不能替代总索引的完整分支。
3. 索引只保留名称、层级与链接；同一资料的中文稿、源文件、答案、在线入口归为一组。使用相对 URL 并逐段编码。默认隐藏 Markdown 和英文重建稿入口；调用方明确要求双语视频或原文对照时保留对应 HTML 入口。
4. 缺少或过期的 HTML 阅读页按 [阅读页生成与校验](references/html-readers.md) 构建；只重建受影响文件。该工具同时支持既有报告渲染，报告结构与写作规则仍沿用现状，重做报告须另行提出。
5. 更新所有包含变动分支的索引，复用 `assets/navigation.js` 保存展开状态和滚动位置，并保留“全部展开”“全部收起”两个按钮。
6. 校验相对链接、标题锚点、资源和多层目录可达性；浏览器可用时检查展开不跳页、状态恢复与阅读页返回。结构校验和交互实测分开记录。

## 工具边界与交付

`scripts/build_html_readers.cjs` 负责 Markdown 阅读页渲染以及已有索引的链接、交互升级；它不会凭空建立或递归补齐资料树。新建或补齐树必须根据清单编辑模板。模板占位符需全部替换，不能把示例节点当真实资料。

阅读页与索引的模板、样式、脚本及 Node 依赖均归本技能维护；调用方只保留入口引用，不复制一套实现。旧翻译技能中的阅读页脚本保留兼容转发，实际执行本技能的生成器。

保留现有 `报告.md` / `报告.html` 和调用方提供的说明，报告作为普通文件叶节点；索引单独维护时不要为了凑齐报告而虚构正文或验证结论。报告存在且需要重新渲染时仍使用原有约定。

交付可点击的 HTML 索引链接；报告存在时一并给出。只声明实际通过的检查。
