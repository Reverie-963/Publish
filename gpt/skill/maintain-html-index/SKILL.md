# 文件索引与 HTML 预览

将文件夹变成可浏览的 HTML 入口，点击资料先看到预览，原件保留。默认入口名 `00 - 文件索引.html`，方便按名称排序时靠前；Finder 的文件夹优先、手动排序等设置仍可能影响位置，不保证系统级置顶。

## 工作流程

1. 确定根目录、范围与既有顺序，阅读 [结构与导航](references/layout-and-navigation.md)。课程材料保留网页顺序；普通文件夹沿用自然文件名顺序。用户指定文件名和布局优先。
2. 使用 `scripts/build_folder_index.py ROOT` 生成递归索引和预览，详见 [文件类型与生成](references/file-previews.md)。先在样例或任务范围内运行，检查转换结果，保留所有原件。
3. 严格使用下述界面约定及共享模板，保留目录展开与返回后的滚动位置；不要自行改成文件管理器。
4. 对用户实际需要的类型验证打开效果。无法完整预览时直接写明能力边界，保留“打开原件”，不把下载冒充预览、文本提取冒充原版、空白页冒充成功。
5. 交付真实的离线 HTML 入口及重要限制，不启动 `start_editor.py`、`serve_editor.py` 或目录监听，也不提供 localhost 链接；其他技能调用本技能时同样遵守。只在用户要求更新或当前任务修改了源文件时运行一次增量生成，完成后退出。验证记录放工作区，不要求为了记录验证而新写报告。

## 固定的界面约定

除非用户明确要求改变，生成结果必须同时满足：

- **索引页**：居中的单栏递归文件树，仅显示标题、必要导航、层级和文件链接。文件夹名称可点击进入独立子目录页，箭头保留同页展开/收起；子目录提供上一级和总索引。使用 `assets/navigation-template.html`；不做左目录右预览，不加常驻侧栏、预览框、搜索栏、卡片切换或统计面板。
- **阅读页**：点击资料直接进入独立 HTML。沿用 `assets/reader.css`：与目录页一致的背景、居中单栏宽度和留白，正文直接铺在页面上，不套白色纸张卡片、边框、圆角或阴影；标题、返回链接和分隔线沿用目录页的简洁形式。紫色链接及清晰的表格样式保留。文稿目录为可展开、收起的侧边大纲，首次默认收起，只留灰色细线图标；没有按钮底色、边框或阴影。宽屏以正文自身为视觉中心，左右留白对称，左侧放置工具和大纲；展开只显示图标下方的大纲，不改变正文与图标的位置和宽度；随正文滚动保持可用；点击章节后保持展开，滚动时用紫色标出当前章节。收起仅隐藏大纲，图标仍可随时操作，Esc 可收起；记住用户的展开选择，存储不可用仍可正常切换。窄窗或高倍率下改为顶部紧凑入口，避免挤压正文；所有可提取结构的文档都生成目录：Markdown/HTML 用标题，PDF/Office 用书签或页码，工作簿用工作表，多页图片用页码；具体规则见文件类型说明。只有一个导航目标的短文或单页资料省略入口。标题下方将“返回总索引”和“打开原件”放在同一行，保持小字号和适当间距；不在文末重复原件入口。对照页两侧都保留“返回总索引”和“打开原件”。必要样式内嵌，离线或嵌套路径下不能退化成无样式正文。
- **展开控件**：左侧工具区只放一个无边框、无底色、无阴影的双箭头图标。只要任意层级有一个目录展开，图标含义与动作都是“全部收起”；所有目录关闭时才是“全部展开”。保留按钮语义、键盘焦点、悬停说明和无障碍名称，不显示文字按钮。使用 `assets/navigation.js`，新旧生成接口必须一致。
- **整页缩放**：索引、子目录和阅读页共用 `assets/page-zoom.css/js`，同步缩放正文文字、图片和表格并重新排版；左侧目录图标、侧边大纲、缩放比例与加减控件始终保持 100% 的视觉大小和可点击区域，不随正文缩放。侧栏宽度、间距及吸顶偏移同步补偿，避免留下过宽空白；文件索引树属于内容，仍随比例变化。阅读页的快速访问与文稿目录集中在左侧轻量工具区；缩放使用底部浮动的“− 100% +”，仅在用户调整比例时出现，停止操作 3 秒后淡出，悬停或键盘焦点在其中时保持显示；鼠标／触控点击遗留的焦点不阻止自动隐藏。浮动条置于缩放正文之外，不占版面、不随正文放大；加载或恢复已存比例时不弹出。无大纲文档与对照页沿用相同行为。索引及子目录页仍将全局展开图标与缩放控件横向常驻左侧。工具栏从首次滚动起保持原位，不先随正文上移再吸顶；窄窗工具栏从页面顶部开始排列，背景覆盖左右留白和缩放后的像素边缘，不露出后方滚动内容。单击比例直接恢复 100%，左右加减号直接调整，无下拉箭头或二级缩放菜单；支持页面收到的 Cmd/Ctrl 加减、0 和 Ctrl 滚轮手势；Command 加双指滚动不触发页面缩放，普通滚动不拦截。浏览器允许存储时同一文件夹沿用比例，存储禁用仍可调整；图片不再默认点击打开独立放大界面。不要通过单独放大图片代替整页缩放，不使用 transform 缩放造成裁切。
- **代码与滚动条**：代码文件（含按 MATLAB 着色的 `.m`）及标明语言的 Markdown 代码块在生成时着色，保留完整可复制文本，未知语言显示原文；不执行代码，不依赖在线资源；代码块背景透明，无边框、阴影或卡片外壳。滚动条使用细、浅色圆角滑块和透明底轨，保留原生滚动与拖动，不用自绘滚动层。
- **轻量动效**：宽屏目录开合只淡入大纲，不移动正文与工具栏；窄窗确需移动正文时使用短过渡，首页与快速访问文件树展开/收起约 200ms，只动画最外层变化；侧栏模式切换时轻微淡入；悬停只轻微变色。不加弹跳、循环、整页入场或永久变换。连续点击从当前可见位置衔接，缩放和窗口变化取消未完成动画，保留目录状态、键盘操作与阅读位置；滚动条预留位置，避免开合造成左右跳动。尊重系统“减少动态效果”，此时直接切换。
- **快速访问与双文件对照**：阅读页左侧快速访问图标将同一侧栏切换为按文件夹折叠的文件树，点击文件直接切换预览；文稿目录图标切回当前文件大纲，两种列表不同时占位。当前文件标出；工具区始终保留“自动定位当前文件”和“全部展开／收起”细线图标。自动定位默认开启并记住开关，打开快速访问时展开当前文件的祖先文件夹，只滚动文件树使它可见，不移动正文；手动收起后不立即强制重开。这些图标不随侧栏模式切换隐藏；点击全局控件时显露文件树并执行当前动作。全局图标在任意层级展开时全部收起，否则全部展开；同步 title 和无障碍名称。记住文件树展开状态，存储不可用仍可操作。单页使用鼠标指针拖动形成对照，避免依赖内嵌浏览器的原生文件拖放；保留点击、取消与键盘替代操作。拖动文件到正文左侧或右侧形成双文件对照，放置提示仅在拖动时出现；Shift+Enter 放右侧，Alt+Enter 放左侧。对照页顶部仅显示当前文档名，不重复提供文件下拉菜单；文件切换统一通过快速访问。各区仍可快速切换文件，已有双栏只替换指定一侧，不嵌套新对照页。工具栏保持固定及原始大小，区域之间用留白，两侧工具栏各有低调的返回单文件图标，回到该侧当前文件，不额外占顶栏；窄屏上下排列。首页保持原来的单栏文件树。清单和预览全部本地，不运行服务器、不 fetch 本地 JSON、不读取跨框架 DOM；只接受本索引清单内的文件 ID。
- **存放位置**：入口为 `00 - 文件索引.html`；新增阅读页、子目录页、转换资源和清单继续集中在 `.file-index/`。同一路径的原件保持稳定预览地址，不为布局更新移动原件或散落新 HTML。

复现的是上述阅读体验，不照搬参考课程的内容。实际视觉、DOM 逻辑和本地链接验证分别记录；只做静态或模拟测试不能声称已在浏览器看过。

## 纯离线交付

页面使用相对路径和本地资源，直接打开 HTML 即可阅读；目录、缩放、代码着色和轻量动效保留。没有后台服务、定时扫描、自动刷新或网页编辑写回。原文件在对应本机应用中修改，随后按需增量更新预览；刷新浏览器本身不会重新转换源文件。

“打开原件”默认保留普通文件链接，其打开或下载行为由浏览器决定。用户明确选择后，可按 [本机原件打开器](references/native-originals.md) 安装点击时启动、处理后退出的 macOS 小应用，安装后的索引自动接入；仍不运行后台服务，不把发出调用等同于应用已打开。

旧的编辑与自动同步代码仅作为停用的可选实现保留；除非用户之后明确要求重新启用，不读取其启动流程，也不启动进程。离线交付不需要这些组件。

## 报告独立

本技能不创建、补写或要求 `报告.md`、`任务报告.md`。存在报告时按普通 Markdown/文档处理，自动生成预览并列入文件树；不存在时索引照常工作。需要工作报告时，由任务根据工作量和用户要求另行使用 [task-work-report](../task-work-report/SKILL.md)，报告的结构、续写与待确认事项的突出方式以该技能为准。

论文、课程报告、文章审核版都是普通源文件；不要因名称包含“报告”而重写内容。

## 工具与兼容

文件索引生成器、预览适配器及样式集中在本技能。所有新预览和状态放根目录 `.file-index/`，不散落到材料旁；HTML 离线读取已生成内容，不依赖运行时 fetch 或服务器。源文件的已有相对链接须保持可用。

原 `scripts/build_html_readers.cjs` 保留为同目录 Markdown 阅读页兼容工具，使用见 [旧阅读页接口](references/html-readers.md)。翻译技能旧脚本继续转发到它。新索引不强制重建所有旧 HTML；保留已有有效阅读版与用户页面，不覆写不属于本生成器的同名文件。

索引和报告是独立技能；文档翻译、Moodle 归档和视频文稿只在需要导航时调用本技能，不因调用导航而强制提交报告。
