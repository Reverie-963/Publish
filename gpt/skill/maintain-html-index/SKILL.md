# 文件索引与 HTML 预览

将文件夹变成可浏览的 HTML 入口，点击资料先看到预览，原件保留。默认入口名 `00 - 文件索引.html`，方便按名称排序时靠前；Finder 的文件夹优先、手动排序等设置仍可能影响位置，不保证系统级置顶。

## 工作流程

1. 确定根目录、范围与既有顺序，阅读 [结构与导航](references/layout-and-navigation.md)。课程材料保留网页顺序；普通文件夹沿用自然文件名顺序。用户指定文件名和布局优先。
2. 使用 `scripts/build_folder_index.py ROOT` 生成递归索引和预览，详见 [文件类型与生成](references/file-previews.md)。先在样例或任务范围内运行，检查转换结果，保留所有原件。
3. 严格使用下述界面约定及共享模板，保留目录展开与返回后的滚动位置；不要自行改成文件管理器。
4. 对用户实际需要的类型验证打开效果。无法完整预览时直接写明能力边界，保留“打开原件”，不把下载冒充预览、文本提取冒充原版、空白页冒充成功。
5. 默认运行 `scripts/start_editor.py ROOT`，交付它实际返回的本机 URL，并检查对应阅读页确实带有编辑功能；其他技能调用本技能时也执行此步骤。离线 HTML 作为可移动的只读副本保留。用户明确只要离线/静态输出或环境无法运行本机服务时才省略，交付时写明只读限制，不能声称可保存。验证记录放工作区，不要求为了记录验证而新写报告。

## 固定的界面约定

除非用户明确要求改变，生成结果必须同时满足：

- **索引页**：居中的单栏递归文件树，仅显示标题、必要导航、层级和文件链接。文件夹名称可点击进入独立子目录页，箭头保留同页展开/收起；子目录提供上一级和总索引。使用 `assets/navigation-template.html`；不做左目录右预览，不加常驻侧栏、预览框、搜索栏、卡片切换或统计面板。
- **阅读页**：点击资料直接进入独立 HTML。沿用 `assets/reader.css`：与目录页一致的背景、居中单栏宽度和留白，正文直接铺在页面上，不套白色纸张卡片、边框、圆角或阴影；标题、返回链接和分隔线沿用目录页的简洁形式。紫色链接及清晰的表格样式保留。文稿目录为可展开、收起的侧边大纲，首次默认收起，只留灰色细线图标；没有按钮底色、边框或阴影。宽屏为目录预留固定窄栏，展开只显示图标下方的大纲，不改变正文、图标或缩放数字的位置和宽度；随正文滚动保持可用；点击章节后保持展开，滚动时用紫色标出当前章节。收起仅隐藏大纲，图标仍可随时操作，Esc 可收起；记住用户的展开选择，存储不可用仍可正常切换。窄窗或高倍率下改为顶部紧凑入口，避免挤压正文；所有可提取结构的文档都生成目录：Markdown/HTML 用标题，PDF/Office 用书签或页码，工作簿用工作表，多页图片用页码；具体规则见文件类型说明。只有一个导航目标的短文或单页资料省略入口。正文保留一个“返回总索引”。必要样式内嵌，离线或嵌套路径下不能退化成无样式正文。
- **展开控件**：左侧工具区只放一个无边框、无底色、无阴影的双箭头图标。只要任意层级有一个目录展开，图标含义与动作都是“全部收起”；所有目录关闭时才是“全部展开”。保留按钮语义、键盘焦点、悬停说明和无障碍名称，不显示文字按钮。使用 `assets/navigation.js`，新旧生成接口必须一致。
- **整页缩放**：索引、子目录和阅读页共用 `assets/page-zoom.css/js`，同步缩放正文文字、图片和表格并重新排版；左侧目录图标、侧边大纲、缩放比例与菜单始终保持 100% 的视觉大小和可点击区域，不随正文缩放。侧栏宽度、间距及吸顶偏移同步补偿，避免留下过宽空白；文件索引树属于内容，仍随比例变化。文档页的比例和小箭头与目录图标集中在左侧轻量工具区，随阅读保持可用；目录收起后仍能直接缩放。无大纲文档也沿用该位置，索引页的全局展开图标与缩放控件也集中在左侧；两类页面的控件均横向并排，不上下堆叠。窄窗工具栏贴住视口顶部，背景覆盖左右留白和缩放后的像素边缘，不露出后方滚动内容。单击比例直接恢复 100%，小箭头才展开缩小、复位、放大；支持页面收到的 Cmd/Ctrl 加减、0 和 Ctrl 滚轮手势；Command 加双指滚动不触发页面缩放，普通滚动不拦截。浏览器允许存储时同一文件夹沿用比例，存储禁用仍可调整；图片不再默认点击打开独立放大界面。不要通过单独放大图片代替整页缩放，不使用 transform 缩放造成裁切。
- **代码与滚动条**：代码文件（含按 MATLAB 着色的 `.m`）及标明语言的 Markdown 代码块在生成时着色，保留完整可复制文本，未知语言显示原文；不执行代码，不依赖在线资源；代码块背景透明，无边框、阴影或卡片外壳。滚动条使用细、浅色圆角滑块和透明底轨，保留原生滚动与拖动，不用自绘滚动层。
- **轻量动效**：宽屏目录开合只淡入大纲，不移动正文与工具栏；窄窗确需移动正文时使用短过渡，文件树展开/收起约 200ms，缩放菜单淡入约 140ms；悬停只轻微变色。不加弹跳、循环、整页入场或永久变换。连续点击从当前可见位置衔接，缩放和窗口变化取消未完成动画，保留目录状态、键盘操作与阅读位置；滚动条预留位置，避免开合造成左右跳动。尊重系统“减少动态效果”，此时直接切换。
- **存放位置**：入口为 `00 - 文件索引.html`；新增阅读页、子目录页、转换资源和清单继续集中在 `.file-index/`。同一路径的原件保持稳定预览地址，不为布局更新移动原件或散落新 HTML。

复现的是上述阅读体验，不照搬参考课程的内容。实际视觉、DOM 逻辑和本地链接验证分别记录；只做静态或模拟测试不能声称已在浏览器看过。

## 默认本机编辑与同步

使用 [直接编辑](references/inline-editing.md) 和 [本机自动同步](references/automatic-sync.md) 启动或复用当前目录的服务，不依赖测试目录、旧会话地址或手工修改生成页。MD/DOCX/DOC 点击段落修改；UTF-8 文本、代码（含 `.m`）和配置文件可直接修改源文本。网页保存先备份、检查冲突再写回原件；Word 的复杂对象和版式使用原应用。

macOS 上，Markdown（`.md`/`.markdown`）、常见 Office、PDF、图片、音视频预览中的原件链接接到本机默认应用；用户点击才打开，不增加按钮，不执行代码文件。是否能编辑取决于本机应用，不能将“已打开”或预览转换说成所有格式都支持网页编写。外部保存后由服务更新预览。未知格式保留原件入口，并明确编辑能力边界。

服务仅在运行期间监听选定目录的增删改名，不安装开机启动项。`file://` 仍只读；浏览器草稿、生成的 HTML 或保存中的状态均不是原文件已写入的证据。源码升级后启动脚本检查服务版本，保留旧会话不打断输入，并交付新的可用入口。

## 报告独立

本技能不创建、补写或要求 `报告.md`、`任务报告.md`。存在报告时按普通 Markdown/文档处理，自动生成预览并列入文件树；不存在时索引照常工作。需要工作报告时，由任务根据工作量和用户要求另行使用 [task-work-report](../task-work-report/SKILL.md)，报告的结构、续写与待确认事项的突出方式以该技能为准。

论文、课程报告、文章审核版都是普通源文件；不要因名称包含“报告”而重写内容。

## 工具与兼容

文件索引生成器、预览适配器及样式集中在本技能。所有新预览和状态放根目录 `.file-index/`，不散落到材料旁；HTML 离线读取已生成内容，不依赖运行时 fetch 或服务器。源文件的已有相对链接须保持可用。

原 `scripts/build_html_readers.cjs` 保留为同目录 Markdown 阅读页兼容工具，使用见 [旧阅读页接口](references/html-readers.md)。翻译技能旧脚本继续转发到它。新索引不强制重建所有旧 HTML；保留已有有效阅读版与用户页面，不覆写不属于本生成器的同名文件。

索引和报告是独立技能；文档翻译、Moodle 归档和视频文稿只在需要导航时调用本技能，不因调用导航而强制提交报告。
