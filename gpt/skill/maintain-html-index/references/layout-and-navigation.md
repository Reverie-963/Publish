# 同目录文稿、HTML 阅读版与统一导航

文档翻译、视频转文稿和 Moodle 归档保持独立技能，共用以下组织与导航规范。用户指定的位置或结构优先，只维护当前任务范围。

## 文件结构与正文来源

```text
课程目录/
  index.html
  报告.md
  报告.html
  assets/html-reader/       # 离线阅读样式与公式字体
  板块/
    index.html
    01 - 资料.pdf
    01 - 资料.zh.md
    01 - 资料.zh.html
    assets/01 - 资料/
  99 - 归档/               # 仅需要时保留旧内容
```

- 文档翻译默认仅翻译为中文，输出完整 `.zh.md`，再从它生成完整 `.zh.html`；不默认新增 `.original.md`／英文 Markdown。已有英文稿保留在本地，默认隐藏 `.original.md` 及对应 HTML 的导航入口，不新增英文阅读页；仅用户明确要求英文对照时展示。其他目标语言遵从明确请求。视频语言输出由独立视频技能决定。
- Markdown 是本地编辑与校对依据，HTML 是从它生成的网页阅读版；不分别编写两套正文，不拆成单页副本。更新 MD 后重新生成受影响的 HTML，改名/移动时同步维护两者和入链。
- 原件保留原位；新增文稿和阅读页与源文件同目录，沿用完整 stem、编号。图片放 `assets/<source-stem>/` 并供 MD/HTML 共用，必要的共享阅读样式和字体放 `assets/html-reader/`。
- 仅重做索引或增加阅读页时，不额外搬迁既有正文和资源。不得因技能更新自动整理其他课程。提取稿、机器记录、测试、脚本与临时图放任务工作区，不进入正式阅读目录。

## 简洁 HTML 索引

用户说“索引”时指 `index.html`。使用 [离线导航模板](../assets/navigation-template.html)，保留原生 `<details><summary>` 折叠树及相对链接。

- 总索引在同一页内递归呈现“板块 → 子目录 → 资料 → 文件”的完整折叠树。文件夹/板块用 `<details><summary>`，点击名称只展开或收起；只有具体文件、阅读页和在线入口使用链接。不能只折叠第一层，再让用户点击子 `index.html` 才能看到资料。同一资料的中文稿、原文稿（原始 PDF／Word 等文件）、答案和在线入口归在同一节点，不为显示分组新建实体文件夹。
- 已有子索引可保留以兼容旧链接或独立打开，但总索引必须直接包含其资料分支，不能以子索引跳转代替展开。只有用户明确要求分页面导航时例外。子目录内容变化时同步所有包含该分支的上级索引；嵌入分支时重算相对链接，报告在每棵树只保留一个入口。
- 完整树在生成阶段写入 HTML；不依赖运行时 `fetch`、iframe 或服务器加载子索引。沿用原始资料顺序、全部展开/收起和展开状态保存，不因改成同页树搬迁文件。
- “中文稿”“答案”“报告”指向 HTML 阅读页；“原文稿”指向原始 PDF／Word 等源文件，不指向英文 Markdown 或其 HTML。普通翻译节点按“中文稿、原文稿、在线入口”排列（仅列真实存在的项）；源视频可标为“原视频”。MD 仅在本地保留，网页不显示 MD 文件入口。没有生成对应 HTML 时，不能假装有网页阅读页，应补齐生成或如实说明限制。
- 索引只显示标题、资料名称与必要跳转（上一级、总索引、课程页面）；不放摘要、状态标签、日期、统计、表格、卡片、缺失说明或日志。
- 报告作为索引树中的普通文件叶节点 `报告.html` 显示，不放在页头导航；子索引需要报告入口时也使用文件叶节点，并指向同一根报告。
- 不展示资源文件夹和逐张图片。没有本地文件的条目保留有效在线入口，原因放报告；不制造失效或禁用的本地链接。
- 页头必要的“上一级/总索引”链接指向具体 `index.html`，不用于替代树中的文件夹展开。本地路径逐段 URL 编码，HTML 文本与属性转义。线上入口沿用已核实来源，不猜测。不依赖 CDN、服务器或网络字体，不为强制唤起应用安装协议或更改系统设置。

## 默认紫色强调色

索引、报告及共用 HTML 阅读样式采用接近 GPT 紫色强调色观感的配色，不声称是官方精确色值。浅色模式强调色为 `#7c3aed`，轻背景为 `#f3efff`；深色模式强调色为 `#c4b5fd`，轻背景为 `#352b49`。用于链接、目录展开标记、按钮文字与键盘焦点、悬停背景和引用边线；正文与页面背景保持中性色，错误或警告保留语义颜色。

样式来源是 `assets/navigation-template.html` 和 `assets/reader.css`；调整配色时同时维护模板、当前任务范围内的既有索引及本地阅读样式副本，避免重新生成后恢复旧色。课程归档与视频稿沿用本共享规范，不另存一套配色。用户明确指定其他配色时优先遵从。

## HTML 阅读页与目录

使用 [阅读页生成与校验](html-readers.md)。每份完整 MD 生成一份完整 HTML，保留所有章节、图片、表格、公式及有效引用。

- 按真实标题层级生成目录，标题锚点唯一；重复标题不能冲突。目录支持章节／幻灯片跳转，使用可左右收起的侧栏，默认收起；收起时正文在整个视口居中；展开时侧栏占据左侧空间，正文向右移动并在剩余区域居中。不使用遮罩、调暗背景或阻挡正文点击；窄屏按比例缩小侧栏。提供清晰的展开／收起按钮、Esc 关闭与键盘访问，窄屏也能操作。不要按页另存内容副本。
- 不设置阅读页顶部导航栏；在正文区域只提供一个“返回总索引”，报告也同样处理。去除旧文稿中重复的辅助导航段（不改正文引用或本地 MD），不显示板块索引、报告、Markdown 文件等快捷栏。阅读页正文中的本地 MD 互链指向已经存在的对应 HTML，并维护片段；MD 本身继续链接本地 MD 供本地阅读。
- HTML 从 MD 构建，图片共用原资源；公式在生成阶段渲染并附本地样式/字体。不在本地网页中依赖 fetch 读取相邻 Markdown（file:// 可能受限制）。不把 Markdown 原样放进 pre 当成阅读版。
- 区分文件存在、标题片段存在、公式语法通过和实际浏览器视觉验证。未实测的行为要在报告注明，不能把结构检查当成显示验证。
- Typora 中的原有完整文稿、页内标题及跳转继续保留。HTML 采用可验证的标题 ID；改标题时同步修复入链，不以单页副本解决定位问题。

## 独立报告：HTML + Markdown

用户说“报告”时默认交付 `报告.html`，同时保留 `报告.md`。每个课程或独立任务根默认一对，子索引链接同一 HTML 报告；不为每个子目录堆积报告。

- 在 MD 中维护范围、更新与复用情况、来源 URL/活动 ID 和本地文件对应关系、覆盖范围、缺页/截断、锁定条件、缺失文件、版本差异、校验结果及未验证事项，再生成 HTML。
- 保存旧索引里的用户说明和有效历史信息；更新当前结论并移除已解决的障碍，不能丢弃用户记录。课程实质教学说明独立保存为正文 MD/HTML，不能塞入管理报告。
- 报告的 HTML 和 MD 都返回总索引；HTML 只保留正文中的一个返回链接，不提供本地 MD 入口。翻译更新不能覆盖抓取记录，归档更新不能覆盖翻译覆盖范围或用户说明。

## 安全迁移与链接维护

- 只有本次范围内的纯导航 README/旧索引需要迁移；先确认不是用户正文。保存快照，将导航转到 HTML、说明转到报告，修复入链，再把旧索引移到可恢复归档。不并列维护两套有效索引。
- 已有同名 HTML/报告若用途不同，不覆盖；选择明确文件名并更新引用。阅读页生成器只能覆盖自身生成的页面。
- 需要移动时先记录旧→新路径映射和快照，检查重名。每条引用从旧位置解析绝对目标，经映射再计算新相对路径；同步 HTML、MD、报告、资源、查询和片段。原件和用户内容不得丢失。

## 交付检查

检查 MD 与 HTML 覆盖对应、目录锚点唯一有效、图片/字体/样式本地目标有效、全部索引能到达成果、无新增断链；明确记录既有缺失。原始文件保留，正文修改仅限授权翻译或有依据的修复。

索引检查必须覆盖至少一个多层分支：总索引直接包含子目录的实际文件链接，树内没有把本地子 `index.html` 当作文件夹的链接，嵌入后的目标路径与原子索引一致。浏览器可用时确认展开子目录不改变当前 URL，并检查全部展开/收起及返回后的状态恢复；无法实测时明确区分结构检查与交互实测。

最终回复直接贴可点击的 **“打开 HTML 索引”** 和 **“查看 HTML 报告”**，指向实际文件的绝对路径，不只报名称或要求用户自行寻找。MD 保留在本地，无须作为默认最终交付链接。点击入口不等同于已经验证浏览器显示效果。

## 索引状态与目录跳转

- 点击阅读页目录跳转章节后，侧栏保持当前展开状态，不自动收回；只用收起按钮或 Esc 关闭。
- HTML 总索引及板块索引记住各层展开状态；进入文档后返回索引、刷新页面时恢复，并尽可能恢复滚动位置。每个索引独立保存，以层级标题路径识别节点，避免新增或重排资料导致错误展开。
- 索引标题右侧并排放置“全部展开”和“全部收起”两个独立按钮，固定文字，不合并为切换按钮。无可折叠节点时禁用按钮。窄屏整组可自然换行，不挤压标题。操作结果也保存。使用本地浏览器存储，兼容存储不可用的情况，不依赖服务器；文件路径改变或浏览器清除存储后状态可重置。
- 使用 `assets/navigation.js`（本索引技能内）及已含交互的导航模板；生成器 `--update-indexes` 会同步加入或更新交互。检查返回恢复、全部展开／收起及目录跳转保持展开；静态或模拟测试不能冒充浏览器实测。
