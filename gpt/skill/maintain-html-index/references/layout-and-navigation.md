# 文件结构与导航

## 文件与顺序

- 原件保留原位；新入口默认 `00 - 文件索引.html`，生成内容集中在 `.file-index/`。整个文件夹可一起移动，所有链接使用逐段编码的相对 URL。
- 递归展示完整目录。目录箭头展开，名称进入独立子目录页，资料链接直接打开独立阅读页。总索引仍递归包含全部层级，子目录页只显示当前目录及其后代；提供上一级和总索引链接。空目录也可进入。沿用用户指定顺序、课程网页编号；不通过搬迁文件实现显示分组。
- 不扫描符号链接、隐藏目录、node_modules、内部预览目录；assets 等配套资源不单独列为资料。用户的独立图片目录要作为资料展示。需要排除其他目录时显式传 `--exclude`，不要仅因名称含“work”就省略正文。
- 源 Markdown 与同名有效生成 HTML 合并展示；默认选择 HTML 预览。保留 Markdown 原稿。用户请求纯文件视图时可用 `--include-originals` 展示原语言重建稿，否则 `.original.md/.original.html` 默认隐藏。双语视频工作流明确启用该选项。
- 已核实的在线入口可通过 `--links` JSON 清单加入，字段为 `label`、`url` 和可选 `folder`；只接受 http/https，资料源顺序按清单保留，不猜测 URL。

## 界面与控件

严格沿用 SKILL.md 的固定界面约定。索引的树、样式和图标来自 `assets/navigation-template.html`，状态脚本来自 `assets/navigation.js`；兼容生成器也读取同一套资源，避免两个接口产生不同体验。索引与阅读页统一采用左侧横排工具区；紧凑模式顶部吸附不留缝，背景覆盖两侧留白。浅色强调色为 `#7c3aed`，深色为 `#c4b5fd`。

全局控件检查所有 details，包括父目录收起时隐藏的子目录：任意 open 就全部关闭，否则全部打开。手动展开、全局切换、返回恢复后都须同步图标、title 和 aria-label。无目录时禁用控件。浏览器允许存储时保存展开层级和滚动位置；存储不可用仍可操作，不承诺跨浏览器同步。

独立阅读页复用 `reader.css` 加 `preview.css`，关键样式内嵌；滚动条统一读取 `scrollbar.css`，代码配色和整页缩放分别使用 `code.css`、`page-zoom.css/js`，不要在调用技能里复制实现。文章目录由 `reader.js` 管理可收起的侧边大纲；宽屏左右对称预留空间，使正文自身居中；左侧工具和目录开合不改变正文与工具区的位置，灰色细线图标随阅读保持可用，导航后不自动收起，当前章节随滚动更新。首次收起，后续恢复用户选择；窄窗与高倍率采用顶部紧凑入口，单标题文稿省略目录。正文采用与索引一致的平面网页布局，不使用纸张卡片；这项外观设置不改变文件的预览内容转换方式。HTML 原件可在正文区域内使用受限 iframe，属于该文件的内容，不得据此恢复双栏文件浏览器。不执行 Markdown 内的脚本。

子目录页面集中在 `.file-index/folders/<路径摘要>/index.html`，资料预览地址保持不变。进入目录与折叠是两个独立动作，不能用点击文件夹名称只切换折叠来代替进入。各页面的展开和滚动状态独立保存。

## 增量与兼容

生成器用源文件摘要与适配器版本复用预览。内容变动时重建；原件 SHA 不改变。损坏或缺依赖时生成明确的限制页面，不能继续显示旧预览冒充最新结果。

不覆盖没有生成器标记的同名入口。既有 `index.html` 若是本工具/旧工具生成且用途明确，可以保留兼容跳转并修复受影响返回链接；无授权不删除用户页面或批量迁移其他目录。旧导航的唯一用户说明先保全，不能自动塞进新的简洁任务报告。

## 验证

检查全部本地 href/src、预览覆盖、嵌套目录、中文/空格/# 路径、无报告目录、损坏与未知类型、重复运行不变、源文件不变。交互测试覆盖完全收起、部分展开、全部展开、隐藏子目录展开、恢复状态、存储不可用；实际浏览器检查独立阅读页、返回、文章目录、窄屏及离线 file:// 使用；不能把结构检查当视觉验证。

报告是可选普通文件；只列真实存在的文件，不生成占位报告或空报告。

## 快速访问与双文件对照

`assets/compare.js` 提供阅读页左侧的快速访问文件树。工具按“快速访问、文稿目录”横向排列；紧邻常驻显示自动定位与全局展开／收起图标。自动定位默认开启且可关闭；进入快速访问时展开当前文件祖先，只调整文件树自身的滚动位置。手动收起不触发强制展开。图标不随侧栏模式切换隐藏；点击全局控件时显露文件树并执行当前动作。任意层级展开时全局动作是全部收起，否则全部展开。文件树使用约 200ms 高度过渡，只动画最外层变化；连续操作从当前可见位置衔接，窗口变化、缩放和减少动态效果立即取消动画。缩放条只在调整比例时浮现于底部，3 秒后自动隐藏，悬停和键盘焦点期间保留；鼠标／触控点击遗留的焦点不暂停倒计时，失焦或切到后台时关闭。快速访问与文稿目录共用侧栏，点击文件进入预览，当前文件高亮；保留目录层级、折叠状态及普通链接，不能依赖网络或后台服务。

从文件树拖动到正文左侧/右侧，进入 `.file-index/compare.html`，所拖文件放到指定一侧，当前文件放到另一侧；Shift+Enter/Alt+Enter 分别提供右侧/左侧放置的键盘方式。放置区域只在拖动中出现，取消时移除；拒绝其他索引的拖放数据和不在清单中的文件 ID。

清单位于 `.file-index/assets/file-catalog.js`。两侧独立滚动，区域间只留白；“返回单文件”回到左侧文件。窄屏上下排列。顶部只显示文档名，完整路径放入悬停说明；文件切换由各区快速访问控制，放置操作由外层处理，不嵌套对照页。保留中文、空格和特殊字符路径。

工具栏从顶部开始，不先随正文滑动。外层文档名仅在阅读页未准备好时保留；通过校验来源窗口和当前预览 ID 的消息切换文件，不读取跨框架 DOM，不轮询。单文件窄屏工具栏同样从顶部开始，宽屏吸顶偏移与初始位置一致。

`tests/check_compare.cjs ROOT` 覆盖文件定位、全局折叠、设置恢复、拖放与对照通信；`tests/check_transient_zoom.cjs ROOT` 使用可控时钟检查浮动缩放条的显隐、悬停、焦点及切页恢复，不代表浏览器视觉验收。

单页拖动采用指针事件：超过短距离阈值后显示左右放置提示，释放时进入对照，取消、失焦或 Esc 清理提示，拖动后不再触发链接点击。保留原生拖放作为补充，其提示延后一帧显示，避免打断拖动启动。只有明确标记 `compare-pane=1` 的页面才按对照子页处理，不能将内嵌浏览器的普通 iframe 误判为双页。
