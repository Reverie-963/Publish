# 本机编辑与原文件同步

默认随索引交付本机入口；用户明确只需离线/静态文件时才省略。启动服务不会修改源文件，只有用户编辑保存才写回。

## 启动

使用具有预览依赖的 Python 运行以下入口；新文件夹会先生成索引，已有清单保留原选项。需要特定标题、排序或排除范围时，先按这些选项生成索引：

```bash
python3 scripts/start_editor.py /absolute/folder
```

返回本机编辑入口 URL。从这个入口打开 `.md`、`.docx`、`.doc`、UTF-8 文本与代码文件，点击内容即可修改，不增加编辑/保存按钮。服务只监听 `127.0.0.1`，同一目录再次启动会复用现有服务；关闭电脑后需重新启动。文件夹移动后按新路径启动，不承诺旧运行地址仍有效。

`file://` 页面无法静默写入原文件，所以不要给只读文件链接并声称可保存，也不要把浏览器草稿冒充源文件保存。服务入口每次读取原件的最新内容，并在运行期间自动监听选定目录的文件变化、更新离线预览；自动刷新不会打断正在编辑的段落，详见 [本机自动同步](automatic-sync.md)。只读离线标签页仍需手动刷新。

## 交互与保存

- 保持现有单栏排版、左侧目录及缩放控件。点击段落即可编辑，停顿后自动保存；离开段落或按 Esc 恢复阅读排版。Cmd/Ctrl+S 可立即保存。只在返回链接旁显示轻量状态文字，不放工具栏或按钮。
- Markdown 在当前段落显示原始语法，以保留链接、公式、代码、列表等结构；只替换相应的源文本区间，不把整个 HTML 反向转换为 Markdown。新章节在重新打开后加入目录，已有标题的目录文字立即更新。
- Word 编辑页使用流式文字和表格，不把页面截图当作可编辑内容。支持普通段落、标题及表格单元格的文字和换行；DOCX 按文本差异修改普通文字运行，尽量沿用原运行的格式，不改变其他包内文件。图片保留展示；公式、域、修订、超链接等复杂段落不直接编辑，需要 Word；文档保护或修订模式阻止写入。该入口不是完整的 Word 排版编辑器。
- 旧 DOC 通过临时 DOCX 处理并转换回 DOC，确认目标段落文字一致后才写入。旧格式转换可能改变复杂版式；原二进制文件必须备份，不把这种转换描述为无损。
- 纯文本、代码（含 MATLAB `.m`）、JSON/YAML、CSV/TSV 等以源文本编辑，恢复阅读后重新着色；CSV/TSV 不是公式表格编辑器，HTML 是源码编辑。保留 BOM 和换行；非 UTF-8、二进制或超过 1 MB 的文本不直接编辑。
- macOS 的常见 Office、PDF、图片、音视频沿用原件链接，点击后在默认本机应用打开真实源文件。使用需要的本机编辑器保存后，预览自动同步；服务不会安装编辑器，也不承诺默认查看器具有编辑功能。网页内仍有未保存输入时先完成保存；失败则保留输入并停止跳转。未知格式仍保留普通原件入口。
- 原件写入前保存到 `.file-index/history/<id>/<原SHA>.<扩展名>`；先检查源文件修订值，再原子替换。检测到外部修改时拒绝覆盖。失败时保留当前输入；浏览器允许存储时保存草稿，离开有未保存内容的页面时提示。存储不可用时不能宣称草稿已持久化。
- 慢速保存期间继续输入或切换段落时，等待整轮队列写完再退出编辑。重复保存请求复用同一操作标识；响应丢失后的重试不会重复写入，外部修改仍阻止覆盖。
- 普通粘贴只接受纯文本，未授权来源和无写入凭证的请求不能修改文件。服务拒绝越界路径及直接访问备份/运行凭证；原始网页和提取网页即使直接打开也保留 sandbox。

`build_folder_index.py` 是静态生成器；技能默认交付流程还须运行 `start_editor.py` 并验证返回的 HTTP 阅读页，不能在别的任务里只调用生成器就宣称完成编辑接入。发布技能时只发布代码、规则和测试，不发布运行 URL、凭证、日志、草稿或用户文档。

## 验证

- `tests/check_editing.py`：临时副本中的真实 HTTP 保存、Markdown BOM/换行/公式/链接、Word 格式与媒体保留、DOC 转换、表格文字、备份、冲突与路径检查。
- `tests/check_inline_edit.cjs`：需要 jsdom，验证无按钮编辑、自动保存、段落切换、范围更新、Esc、失败与离开提示；仅为 DOM 模拟。
- Word 保存结果另行渲染核对，确认文字、表格、图片与分页；浏览器编辑手感和实际粘贴行为需要独立的浏览器验证，不能用 HTTP/DOM 测试代替。
