# HTML 阅读页生成与校验

用于把已有正文 Markdown 和报告渲染为离线、带目录的 HTML。Markdown 是唯一编辑来源；只在当前任务范围构建，不重新翻译、不新建英文 Markdown。

生成器只渲染正文并升级已有索引，不自动创建或补齐递归资料树；新树先按本技能模板和实际清单建立。

## 生成

技能自带 Node 脚本 `scripts/build_html_readers.cjs`，依赖锁定在技能根 `package.json` / `package-lock.json`。已安装依赖可直接运行；迁移技能后如缺失，先在技能根执行 `npm ci --ignore-scripts --no-audit --no-fund`。不向用户的课程目录安装依赖。

```bash
node "${CODEX_HOME:-$HOME/.codex}/skills/maintain-html-index/scripts/build_html_readers.cjs" \
  --root /absolute/course-directory \
  --update-indexes \
  --manifest /absolute/task-work/reader-validation.json
```

- 默认处理根目录下非归档、非 assets、非 work 的正文 MD（排除 README、AGENTS 与旧文稿索引），对应生成同路径 `.html`。既有英文 HTML 可同步更新样式，但不默认新增英文 HTML；仅明确请求英文对照时使用 `--include-originals`。增量任务用重复的 `--file '相对路径.md'` 限定变更文件；跨文稿引用也需要纳入或确认对应 HTML 已存在。
- `--update-indexes` 更新正文 MD 链接为 HTML，隐藏英文对照叶节点，将原件标为“原文稿”，把页头报告移到索引树中的 `报告.html` 文件叶节点。目录名保持原样；不会删除已有英文文件。
- 阅读页使用 `assets/reader.css` 和 `assets/reader.js` 模板：目录侧栏左右收起、默认关闭；展开时正文向右让出侧栏空间并在剩余区域居中，收起后恢复全页居中。不使用遮罩或调暗正文；只在正文保留一个“返回总索引”，不显示顶部导航和 MD 文件入口。渲染时移除独立辅助导航段，本地 MD 保持不变。
- 使用 Markdown parser 渲染列表、表格、图片和代码；数学支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。KaTeX 在生成阶段输出 HTML/MathML，CSS/字体复制到根 `assets/html-reader/`，无需运行时网络和服务器。
- 原始 HTML 默认转义，不执行文稿里的脚本；独占一段、仅含 `id` 或 `name` 的空 `<a>` 锚点可保留为安全的页内定位点，并纳入片段校验；确有源文档 HTML 表格或嵌入媒体时先检查并实现合适的保留方式，不能以转义源码代替预期图表。
- 脚本不修改 MD；拒绝覆盖不带自身标记的已有 HTML。保留生成元数据中的 MD 内容校验值，便于检查是否过期。
- 缺失文件不生成失效链接；HTML 保留名称并标明缺失，机器记录列明原引用。Markdown 的历史引用不自动删除。缺失图片、公式解析失败、失效片段必须处理或如实记录，不能默默省略。

## 更新与校验

1. 更新正文或 `报告.md`，然后构建受影响 HTML，再更新索引。仅改网页会在下次生成时丢失，不应这么做。
2. 检查所有 HTML href/src 和 CSS 字体引用，包括空格、中文、括号、# 等字符；检查目录中的每个片段实际存在、重复标题具有唯一 ID。
3. 对照 MD 的标题、表格、图片和公式数量，保留源顺序与完整正文；检查代码块中的美元符号没有误渲染。
4. 公式语法检查不能替代理论审校。发现源稿控制字符或确定的转义错误，留快照并做最小修复后重新生成；不为了“通过”而随意改写公式。
5. 浏览器工具允许时，抽查长稿、公式、图片、宽表格、目录展开／收起、Esc 关闭、目录跳转后正文居中和窄屏；工具不允许时不绕过限制，报告区分静态验证和未实测视觉。
6. 使用者收到 HTML 索引与 HTML 报告链接；本地 MD 和必要图片/阅读资源一起保留。
