# 点击打开本机原件（可选，macOS）

用户明确选择后，可安装 `scripts/install_native_opener.py`。安装到 `~/Applications/File Preview Opener.app`，注册 `reverie-preview` 协议；不创建服务、端口、登录项、监听或定时任务。每次点击临时启动，交给应用后自动退出。不要因为生成索引就自动安装。

安装后，生成器自动为本次索引范围内的原件登记链接。登记保存在 `~/Library/Application Support/File Preview Opener/`，只发布代码，不发布该目录、密钥、登记表或含本机链接的生成页面。协议使用不可猜测的文件标识，打开器只解析已登记的普通文件并核对真实路径，拒绝越界、目录和缺失文件。

文档、图片和音视频交给系统默认应用；代码和脚本用“文本编辑”打开，避免执行；其他类型在 Finder 中选中。链接仍叫“打开原件”，不增加常驻控件。普通 `href` 保留相对路径，右键可访问原始文件链接。浏览器可能询问是否允许打开应用，或拒绝自定义协议；无法从纯网页强制绕过，也不能把协议发出当作原件已成功打开。

移动文件夹后重新生成索引；换电脑需在新电脑安装并重新生成，或使用保留的普通链接。取消时将本机 `settings.json` 的 `enabled` 设为 `false`，重新生成索引即可恢复普通文件链接；删除应用前可用系统 `lsregister -u` 注销协议。原文件不会被打开器改写。

验证：`tests/check_native_opener.py` 只验证链接和路径，不启动文档应用。真实启动另选一个用户授权范围内的原件，核对 `last-open.json` 与打开器进程退出；此记录只证明系统接收打开请求，不替代浏览器点击和目标应用显示测试。
