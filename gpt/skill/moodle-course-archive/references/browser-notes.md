# 浏览器与站点细节

需要排查浏览器下载、Moodle 动态页面或外部链接时阅读。这里是处理已观察问题的线索，不是固定按钮或接口脚本；先读取当前工具说明和页面状态。

- **继续使用登录态**：优先操作用户指定且已登录 Moodle 的浏览器。另一个浏览器能显示普通网页，不代表拥有相同 Moodle 会话。
- **读取完整条目**：课程磁贴可能使用弹窗或异步加载。确认板块标题与活动列表已切换；展开 `Show more` 才能完整记录限制。Moodle 文件夹还可能有未展开的子目录。
- **下载与完成状态不同**：打开资源可能按平台规则自动记为已查看；不用点击 “Mark as done” 来为了下载强行推进课程。下载行为不代表完成测验。
- **确认落盘**：点击 Save 或浏览器下载入口后，还需确认文件实际出现在目标路径、下载已结束、格式正确。不能把已弹出保存对话框当作完成。
- **保存对话框**：使用最新界面状态寻找文件名、位置和保存按钮。若按钮禁用，检查正在加载的目录、当前窗口、输入是否有效，再调整；不要反复盲点。切换目录后核对实际保存位置，尤其是 iCloud 路径及含特殊字符的名称。
- **已存在文件**：遇到替换提示先比较目标，不无条件覆盖用户文件。核对用下载存到独立临时目录，确认结果后不留在课程根目录。
- **URL 的含义**：浏览器地址栏、PDF 阅读器地址、资源下载链接和 Moodle 活动入口可能不同。保存 Moodle 入口用于恢复课程上下文；如果另存外部直达链接，用后缀清楚区分。
- **坏链接修复**：如果一个 URL 明显包含另一个完整 URL，不直接按原串下载；将观察到的两个地址分别验证。保留原入口并解释修正，不假定其中任一个仍然可访问。
- **阅读清单**：课程全名搜索可能无结果，而课程代码能匹配。核对结果中的学年；若站点有导出 PDF/Word 的功能，优先用官方导出，不能把网页加载壳当正文。
- **网页编码**：HTML 转 PDF 前正确解码；出现乱码时修正编码后再生成，不交付带替换字符的文章。
- **原 PDF 警告**：能解析页面不等于完全无缺陷。出现显著压缩/缺页问题时，可重新下载同一原件进行比较，并检查受影响页面。若原站文件本身也有警告，保留原件并简要说明；不要未经检查就声称损坏或擅自“修复”内容。
- **权限与验证**：403、登录、真人验证、付费章节与前置课程锁定是不同情况。分别说明实际观察结果；不能把所有打不开的资料都归因于需要先做 quiz。
- **停止条件**：完成一次针对已观察问题的合理重试或正常替代入口核对后，若仍受权限/验证/失效限制，记录入口与下一步，处理剩余材料。不要把反复刷新或更换地址当作进展。
