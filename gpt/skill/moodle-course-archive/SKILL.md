# Moodle 课程资料归档

交付可直接使用的课程文件夹：板块与网页对应，资料按网页顺序排列，保留原件与来源对应；需要浏览入口时调用索引技能。沿用用户指定的浏览器、目录和范围。

## 索引技能依赖

归档完成后读取并使用 [maintain-html-index](../maintain-html-index/SKILL.md)。单独的“维护索引”“更新目录”直接由该技能处理，不需要启动本技能的 Moodle 访问和下载流程。两个技能安装在同一技能根目录。

## 确认范围并建立清单

- 从用户提供的课程页面、截图、当前会话和目标文件夹确定课程、学年、板块范围及保存位置。信息足够时直接执行；只有课程或目标位置无法确定时才询问。
- “其他几个”“继续”“已有的检查一下”通常表示在当前课程补齐并核对；不是重新下载、翻译全部文件或扩展到其他课程。
- 先检查本地资料与已有说明，再读取当前 Moodle 页面。已有同名文件夹直接使用；原有作业、译稿、字幕和图片不能当作临时产物。
- 按网页实际出现顺序记录各板块及条目。记录课程/板块 URL、条目标题、活动 URL/ID、类型、可见顺序、前置条件、本地对应文件和保存结果。**活动 ID 大小、文件名排序、下载先后均不等于网页顺序**；后来新增的活动可能插在旧活动中间。
- 展开文件夹、折叠区和完整限制提示；弹窗或 AJAX 加载完成后核对标题与内容，再读取下一个板块，避免把上一板块误记为下一板块。
- 中间清单、日志、脚本、截图和技术检查记录放在课程目录之外的临时工作区。可保留工作中的恢复记录，但不把它们当作学习资料交付。

## 访问与保存

优先使用能访问该课程的现有连接器或已登录浏览器。浏览器操作遵守当前会话提供的工具及说明；不要从磁盘提取浏览器 cookie、凭证或复制登录资料。普通公开下载可用 HTTP 工具；需要浏览器登录态的文件通过获准的浏览器下载流程取得。

| 网页条目 | 本地保存方式 |
|---|---|
| PDF、PPT/PPTX、DOC/DOCX、XLSX、附件视频等 | 保存原文件，保留真实格式与扩展名 |
| Moodle 文件夹 | 建立对应编号文件夹，展开核对每个子条目，按文件夹内网页顺序编号 |
| 独立文本页面、板块说明、书目信息 | 保存 Markdown 并生成 HTML 阅读版，保留原文结构、有效链接、来源和保存日期；不擅自翻译、补写或作答 |
| 外部文章、普通网页 | 能取得正文则保存 PDF，同时在统一导航中保留来源链接 |
| Quiz、作业提交、签到、调查、其他交互入口 | 保存跳转链接，不开始答题、填写或提交 |
| 在线视频、电子书阅读器、受登录限制的平台 | 有正常可用且允许的下载入口时下载；否则保存入口并明确没有离线全文/视频 |
| 锁定条目或失效链接 | 保存入口，并记录具体原因和用户下一步 |

默认把在线入口直接合并进 `00 - 文件索引.html`（或既有入口），不新增零散快捷方式。用户明确要 macOS 快捷方式时使用有效 plist `.webloc`，不能只改文本扩展名。

网页 PDF 优先使用站点导出或浏览器保存/打印。若使用正文重新排版，标明“网页正文”，保留正文与来源，说明图片、交互或原版布局的缺失；不得将摘要冒充全文。确认文本编码，抽查排版与尾页。首页只归档当前首页，不因包含导航就递归下载整个网站。**登录页、验证码、错误页和空白播放器不是资料正文**。

文件存在时先对照条目、名称、格式和可读性。已对应且可用的文件直接复用，不为验证、改名、排序或版本不明而重新下载。缺失或确认损坏时补齐；同一条目的新版本按下面的增量规则处理。明确区分“本地文件可读”“与网页条目对应”和“与新下载逐字节一致”，不要把一种检查说成另一种。

## 增量更新（已有课程默认）

用户要求更新、继续、补齐，或目标课程目录已有资料时，先读 [增量更新与续传](references/incremental-update.md)。默认只补缺：根据 Moodle 活动身份匹配本地资料，检查当前网页的新增条目、附件及解锁状态；已有可用文件不重复下载。普通“增量更新”不表示替换全部原件，也不表示创建定时监控。

- 已有快捷方式不代表已有离线正文。原来锁定、现在可访问的资料只补取缺失正文；Quiz 等交互项仍只保留入口。
- 以当前网页顺序重新计算编号，同步同一条目的原件、译稿、答案、快捷方式以及目录和 Markdown 本地链接。标题或顺序改变只需改名及维护引用。
- 更新锁定与缺失说明，移除已经解决的提示；没有变化时不下载、不重复改名、不生成重复说明。
- 来源与活动 ID、本地文件映射、锁定条件及恢复状态保留在已有资料说明或任务工作记录，不能删掉唯一来源记录。面向用户只交代影响使用的缺失或需决定的事项。

## 命名与对应关系

- 每个板块建立与网页同名的目录；必要时只清理不合法路径字符。已有板块目录不无故另建一份。
- 条目默认命名为 `01 - 网页条目标题.ext`，在每个板块重新从 01 开始，连续编号。超过 99 项时统一增加位数。
- 下载文件、文件夹、外部链接和测验入口都参与排序。锁定项仍保留自己的编号，避免后续条目错位。
- 同一条目的不同形式共用编号，例如 `08 - Ethics Exercise.docx`、`08 - Ethics Exercise.zh.md`、`08 - Ethics Exercise.zh.html`、`assets/08 - Ethics Exercise/`、`08 - Ethics Exercise - 已填写.docx`。不同条目即使文件内容相同，也要在目录中保留对应关系。
- 单个条目若包含多个链接/附件，优先放入该条目的编号子文件夹，或共用编号加清楚后缀，不假装为多个独立网页活动。
- 页面独立列出的纯书目可以各保存一份编号 MD，并写明仅有书目、没有全文附件。重复书目只保留一份并说明。
- 实质课程说明保存为独立正文；编号与资料一致，需要时由索引技能生成预览。
- 既有文件需改名或移动时，先读 [已有资料改名与链接维护](references/existing-files.md)。同时更新学习目录与 Markdown 本地链接，保留图片资源结构，不能只改外层目录就结束。

## 锁定、损坏链接与访问障碍

“尝试解决锁定”指通过原入口正常访问、展开前置条件、寻找站点已经公开的正确入口；不绕过访问控制，不自动把未学内容标记完成，也不代做前置测验。

- 写明具体是哪项活动阻挡哪份资料，并保存直接入口；仅在页面实际显示时记录通过分数、时限等条件，不从其他课程推测。
- 可以查看测验说明页，但不点击开始、尝试或提交。后续未开放测验的评分规则标为未知。
- 遇到真人验证、登录或权限不足，按工具要求处理。无法在现有授权内继续时保存入口和操作说明，继续其他不依赖它的资料。
- 对坏链接，可拆分明显拼接错误的 URL，或通过站内搜索、课程代码、学年找到正确页面。核对标题、年份和归属，不用旧学年列表替代当前学年。
- 官方旧路径失效时，可以补充经过核实的当前官方入口，标明它可能不是课程旧版原文。无法取得原件就明确缺失，不默默用不明镜像或近似内容替换。
- 重试应解决已观察到的问题；没有新线索时停止重复尝试，把原因与下一步写入说明。涉及浏览器的具体注意事项见 [浏览器与站点细节](references/browser-notes.md)。

## 清理、检查与交付

保留原件、正文及阅读版、译稿、答案、字幕、引用资源和用户说明。来源映射与恢复状态保存在已有记录中；索引与简洁任务报告都不能替代这些原始记录。

默认不交付：机器校验 JSON、下载日志、脚本、临时截图、测试下载副本、重复的审计说明。本次生成的工作材料放在课程目录之外；用户要求清理现有目录时，将确认无用的技术产物移到废纸篓或明确的可恢复位置。不要按“核验”“work”之类词语盲删：带“视频核验版”的文件可能是正式学习文稿。删除完全重复的文件前比较内容并维护引用；保留用户修改版。

进行与变化相称的检查：

- 文件下载完成，类型/大小合理，没有 HTML 登录页伪装成 PDF。
- 新增 PDF 可读并抽查渲染，Office 文档结构有效；必要时检查视频有视频轨道。
- 网页条目与编号对应，锁定/未下载项不遗漏，同一条目不同形式编号一致。
- 改名后目标文件都存在，Markdown 相对链接及图片链接仍有效；内容没有因清理而丢失。

## 调用独立索引技能

每次拉取、增量更新、解锁补齐或整理结束，将课程根目录、受影响文件、网页实际顺序、活动与本地文件的对应关系、已核实在线入口和路径映射交给 [maintain-html-index](../maintain-html-index/SKILL.md)。由它生成受影响的 HTML 阅读页、更新同页折叠树并检查链接；没有变化则不重写。


翻译成果与原件共用编号，默认中文 MD 与 HTML 阅读页置于源文件旁，图片按 `assets/<原文stem>/` 分组；需要实际翻译时才使用 `translate-docs-to-markdown`。不要因归档任务自动翻译或改写用户正文。

旧版本与重复说明仅在用户授权整理时集中放入可恢复归档，并向索引技能提供路径映射以修复引用；不扩展至其他课程。


## 任务报告

不因翻译、归档或生成索引而强制创建报告。任务量较大、存在多项成果或有用户待确认事项时，另行使用 [task-work-report](../task-work-report/SKILL.md)。报告只写已完成和待审核确认，详细来源记录与课程正文单独保留。
